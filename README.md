# Jogo IPRP
Space invaders


## Problemas
No dia 29 de Novembro de 2025 os seguintes problemas foram identificados:
 - Highscores com o mesmo nome
 - Só devem ser adicionados ao highscore os resultados maiores ao último valor dos highscores
 - As vidas não estão a ir embora
 - Não estão as vidas conciliadas com os corações

## Problemas Resolvidos
No dia 2 de Dezembro de 2025 foi resolvido o seguinte:
 - As vidas estão a desaparecer quando o utilizador é abatido
 - As vidas estão conciliadas com os corações
